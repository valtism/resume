# Resume

A cute lil' resume based on my terminal.

## Run dev server locally

Install dependencies:

```bash
bun install
```

Run dev server:

```bash
bun run dev
```

# Run production build lcoally

Install dependencies:

```bash
bun install
```

Build for production:

```bash
bun run build
```

Serve production build:

```bash
bun run preview
```
